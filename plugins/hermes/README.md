# hermes plugin

This plugin adds completions for the Hermes AI agent.

To use it, add `hermes` to the plugin array in your zshrc file:

```zsh
plugins=(... hermes)
```

## Usage

```zsh
hermes <TAB>
```

## Common Workflows

```zsh
# First time setup/updating overall config
hermes setup

# Starting the tui chat
hermes

# Changing default model
hermes model
```
