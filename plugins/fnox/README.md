# fnox

Adds shell integration and completions for [fnox](https://github.com/jdx/fnox), a tool for provider-agnostic secret injection.

## Installation

[Install fnox](https://fnox.jdx.dev/guide/quick-start.html), then add it to your plugins in `~/.zshrc`:

```zsh
plugins=(fnox)
```

## Usage

See the [fnox documentation](https://fnox.jdx.dev/guide/shell-integration.html) for shell integration and usage.
